# Pointsanity reference maps

Full renders of every Commander Keen 4/5 level that contains a **5000-point
pickup** (CK4 *Ice Cream Cone*, CK5 *Bag O' Sugar*), with every pickup stamped at
its exact in-game position — including the ones hidden inside walls / spawned
from the info layer that you can't normally see.

These are **reference images**, regenerated by
`../tools/render_pointsanity_maps.py`, not hand-edited tracker assets.

## Notes

- Each pickup is stamped at native (16x16) scale with the real in-game item
  graphic (foreground tile 1657 for CK4, 1042 for CK5).
- Pickups are found by scanning the map: info-layer spawns (info value 66) plus
  foreground tiles flagged `MF_Points5000` (misc 26). Counts and order match the
  apworld's `pointsanity_ck{4,5}.md` worksheets exactly.
- **`ck4_pyramid_of_the_forbidden` and `ck5_korath_iii_base` are extra:** those
  levels are **not in the Archipelago world right now**, so their 5000-pt items
  aren't randomized or tracked. They contain pickups in-game, so they're rendered
  here as a complete reference; ignore them if you only care about the AP set.

## Rendering

These maps come straight from the original game data (`omnispeak-ap/bin/*.CK{4,5}`)
rendered at exactly 16 px/tile, origin (0,0) — so `pixel = tile * 16` is exact.
The tracker's own `Ck?lv??.png` images are cropped to varying, non-tile-aligned
boxes and can't be used for this.

```bash
python3 tools/render_pointsanity_maps.py   # writes pointsanity_maps/ and extralife_maps/
```
