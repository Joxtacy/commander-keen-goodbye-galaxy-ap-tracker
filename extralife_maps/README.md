# Extra-life reference maps

Full renders of every Commander Keen 4/5 level that contains an **extra life**
(CK4 *Lifewater Flask*, CK5 *Vitalin Keg*), with every pickup stamped at its exact
in-game position — including hidden / info-layer ones.

These are **reference images**, regenerated by
`../tools/render_pointsanity_maps.py`, not hand-edited tracker assets.

## Notes

- Pickups are found by scanning the map: info-layer spawns (info value 67) plus
  foreground tiles flagged `MF_1UP` (misc 27).
- The CK4 flask is a foreground tile (1658), so it's stamped at 16x16. The CK5
  keg has **no** foreground tile (it's only ever an info-layer spawn), so it's
  decoded from EGAGRAPH sprite chunk 222 (32x25) and centred on the pickup tile.

See `../pointsanity_maps/README.md` for how the maps are rendered.
